# Гримхолд 3D · Хроники Пепельного перевала

Одиночная RPG от первого лица в духе TES: Shadowkey и Daggerfall — низкополигональный
мир, стилизованный под PlayStation первого поколения, но собранный на современном
рендере: динамическое освещение, каскадные тени, частицы, постобработка.

Игра целиком помещается в один HTML-файл и работает без сервера. Android-версия —
тот же файл в WebView, плюс нативные мосты для сети.

**[Играть в браузере](https://giperzvuk.github.io/Grimhold3d/)** ·
**[Скачать APK](https://github.com/Giperzvuk/Grimhold3d/releases/latest)**

---

## Что внутри

- Открытая долина с настоящим рельефом: холмы, низины, русло реки, броды, лес, пещеры,
  шахта, крипта. Здания проходимы снаружи и внутри, переходы между локациями с подгрузкой.
- Все объекты — трёхмерные модели, а не спрайты: трава, грибы, паутина, дрова, оружие,
  броня, утварь. 45 моделей предметов, вид от первого лица со своей моделью в руках.
- Бой с замахом, блоком и парированием в окно замаха; стая обходит с флангов, раненые
  бегут. Заклинания, зелья, отравление, голод, жажда, холод, усталость, сон.
- Ремесло: ковка, готовка, алхимия, зачарование. У каждой активности своя мини-игра —
  штифты в замке, точки удара молотом, удары киркой по жиле.
- Сюжет с чёрным юмором: пять концовок, шесть заданий, дневник, карта, торговцы.
- Онлайн-озвучка реплик через Fish Audio (по желанию, со своим ключом).
- Управление: сенсорное с настраиваемой раскладкой, гироскоп, клавиатура и мышь.

## Обновление прямо из игры

В игре есть пункт меню **«Обновление»**. Он спрашивает у GitHub файл
[`version.json`](version.json), сравнивает `versionCode` со своей сборкой и,
если версия новее, показывает список изменений.

- **В APK** игра сама скачивает новую сборку, сверяет SHA-256 и открывает установщик
  Android. Прогресс и сохранения не теряются — обновление ставится поверх.
- **В браузере** кнопка ведёт на страницу релиза.

Проверка идёт не чаще раза в 6 часов, отключается галочкой в настройках, а конкретную
версию можно пропустить. Если `version.json` недоступен, игра спрашивает последний релиз
через API GitHub.

Чтобы обновление ставилось поверх установленной игры, **все сборки должны быть подписаны
одним ключом**. Ключ (`grimhold.keystore`) намеренно не лежит в репозитории — храни его
отдельно и не теряй: с новым ключом Android потребует удалить игру перед установкой.

## Сборка

```bash
python3 build_html.py     # dist/Grimhold3D.html (всё внутри) и docs/index.html (babylon с CDN)
bash    build_apk.sh      # dist/Grimhold3D.apk
```

APK собирается без Android Studio и Gradle: `aapt2` → `ecj` → `d8` → `apksigner`.
Пути к инструментам заданы в начале `build_apk.sh`. В CI то же самое делает
`.github/workflows/release.yml` инструментами из Android SDK, который уже стоит на раннере.

## Релиз

```bash
python3 tools/release.py 1.9 --notes "Что изменилось" "И ещё"
git add -A && git commit -m "v1.9" && git tag v1.9 && git push --follow-tags
```

Скрипт поднимает версию сразу в трёх местах (манифест Android, `VERSION` в `game/game.js`,
`CODE` в `game/update.js` — расхождение здесь ломает обновление), пересобирает HTML и APK,
считает SHA-256 и переписывает `version.json` и `CHANGELOG.md`.
По тегу `v*` workflow создаёт релиз и прикладывает `Grimhold3D.apk` и `Grimhold3D.html`.

## Тесты

```bash
npm install
node tests/bughunt.js     # 28 проверок: рельеф, дома, предметы, мини-игры, утечки
node tests/updtest.js     # механизм обновления
node tests/test3.js       # полный прогон сюжета
node tests/t3d.js         # скриншоты
```

## Структура

```
game/          исходники игры (модули грузятся по порядку из index.html)
android/       WebView-обёртка: activity, мосты озвучки и обновления, провайдер APK
tools/         release.py, прокси для Fish Audio (FastAPI и Cloudflare Worker)
tests/         сценарные проверки на Playwright
docs/          сборка для GitHub Pages
version.json   манифест обновления — его читает игра
```
